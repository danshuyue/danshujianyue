## 关于 AI 的使用

这个仓库里的代码有一部分是在 AI 助手的协作下写出来的。

我的做法是：**AI 负责加速，我负责判断**。每一个提交都自己读过、跑过、验证过，
提交信息里会注明 AI 的参与情况，踩过的坑也都如实写进 README ——
包括 AI 给错方向的地方，那部分往往比顺利的部分更值得记。
